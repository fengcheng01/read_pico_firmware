# 阅读产品界面 / Reading product UI

本分支在原驱动与阅读引擎上重构产品界面，不是完整 OS 发布。普通冷启动进入“正在读”，工厂 VCOM 标定与设备自检续跑仍优先。全局菜单与产品页底栏只有“正在读 / 书架 / 今日 / 设置”四个根入口；原硬件概览及诊断经“设置 → 进阶与诊断”访问。

This branch rebuilds the product UI atop the existing drivers and reading engine, not a complete OS release. Normal cold boot enters Now reading, retaining factory VCOM/self-test priority. Global navigation and product footers expose only Now reading / Library / Today / Settings. Original hardware overview and tests are reached through Settings → Diagnostics.

## 使用 / Use

- 首页顶栏电池按剩余电量实心填充，百分比在黑色填充区显示白字、未填充区显示黑字；0%为空，未知为空并显示“--”。图标尺寸不变、绘制不分配内存，电量变化时仅更新顶栏，不主动读取硬件。阅读剩余时间按本次开书后最近32次、每次3～120秒的向前翻页速度估算，至少8次有效翻页才显示；超过一小时/一天分别改用小时/天，不再固定999分。回翻、目录/进度跳转、工具面板与锁屏停留不训练速度；重新开书重新采样，原累计阅读统计保留。估计依据书籍逻辑字节进度，章节内容密度差异仍会带来波动。
  Home fills the battery in proportion to charge, with white percentage glyphs over black fill and black glyphs over empty space; 0% is empty and unknown is empty with “--”. Dimensions stay unchanged, drawing allocates no memory, and charge changes update only the header without hardware reads during rendering. Remaining time uses the latest 32 forward turns of 3–120 seconds since opening, requiring eight samples; long estimates use hours/days instead of 999 minutes. Backward turns, TOC/progress jumps, tools and lock-screen dwell do not train speed. Reopening restarts sampling while preserving cumulative statistics. Logical book-byte density still makes this an estimate that varies between chapters.
- 正文静止、排版和下一页预绘完成后，心跳由5ms放宽至最多50ms，触摸输入可提前唤醒；触摸采样仍保留原8ms活动/20ms静止兜底，滑动、长按、菜单、晃动和定稿继续快速调度。蓝牙使用板上主晶振在BLE事件间休眠，不假设存在外部32k晶振；自动重连失败完成后依次等10/20/40/80/160/300秒（之后最多5分钟一次），连接成功或主动连接重置退避。未改CPU频率、面板/存储时序或锁屏策略；实际电流与响应仍需真机验收。
  Once body layout and next-page prefetch settle, the heartbeat relaxes from 5ms to at most 50ms and input can wake it early. Touch sampling retains its 8ms active/20ms idle fallback; gestures, holds, menus, shake and settling stay fast. Bluetooth sleeps between BLE events using the main crystal, without assuming an external 32k crystal. Completed reconnect failures wait 10/20/40/80/160/300 seconds, then at most one retry per five minutes; success or manual connection resets backoff. CPU frequency, display/storage timings and lock policy are unchanged; current and responsiveness require device acceptance.

- 固件名为 PageRest，独立于机型；当前只在设置页版本行显示，页眉仍使用设备品牌名。首页续读/打开书架/导入图书共用独立的 604×96 主按钮，统计和同步反馈占下一行，不与按钮重叠。上传仍为 176×88，并保留四周 8px 容差；统计不可点，最近每本只显示一次百分比。加载中主按钮与“全部图书”打开书架，不提前打开未完成的摘要。
  PageRest identifies the firmware independently of the target and currently appears only beside the Settings version; headers retain hardware branding. Resume/Open Library/Import share a separate 604×96 primary action, with stats or sync feedback on the next row. Upload retains 176×88 and 8px tolerance on all sides. Stats stay inert and each recent book shows one percentage. During loading the primary action and All Books enter Library without opening incomplete summaries.

- 首页显示上次可用图书、已保存进度与最多三本其他最近阅读。EPUB 封面按 container→OPF→manifest 定位（cover-image 属性、meta cover、常见文件名回退），单个后台任务有界提取并缩放，tick 领取完整卡片位图；TXT/无封面书改为确定性生成封面：按书路径种子在三种几何版式（深底藏书票、近白留白、上下分割）中选定一种绘制灰阶组合，不画文字（书名排版仍在卡侧），重绘成本低故不做 TF 缩略图缓存，生成失败才回退文件名排版，失败不阻塞书架。没有有效 `last` 时回退最近有效进度；没有阅读记录时提供书架/导入入口，不展示示例书。
  Home shows the last available book, saved progress and up to three other recent books. EPUB covers are located via container→OPF→manifest (cover-image property, meta cover, common-name fallback) and extracted one bounded per tick into the card bitmap; TXT/coverless books now get deterministic generated covers: a path seed picks one of three geometric layouts (dark bookplate, near-white whitespace, split panel) drawn in grayscale without text (the title still typesets beside the card), cheap enough to redraw that no SD thumbnail cache exists, with the typographic fallback only on generation failure and nothing blocking the shelf. Missing `last` falls back to the most recent valid progress; an unread library offers shelf/import actions without demo books.
- 点“继续阅读”或最近图书，是明确的单次开书请求；首帧前验证实际挂载与文件，然后按原阅读器恢复章节、文本偏移和字号。路径不存在或解析失败留在可用书架，显示原错误，不打开演示正文。
- 开书是持久化事务：解析前先把路径写入启动状态，成功才清除；断电或崩溃打断开书后，下次开机日志标明中断书目，续读询问自动跳过该书一次（书架手动打开不受影响，成功即解除）。开机首帧上屏前视为未完成启动，同样留痕。
  Opening is a persisted transaction: the path lands in startup state before parsing and clears only on success; a power cut or crash mid-open makes the next boot log the interrupted title and skip the resume prompt for that book once (manual opening stays allowed and success lifts the block). A boot counts as complete only after its first full frame reaches the panel, leaving the same trace.
  Continue or a recent-book tap explicitly requests one open. After validating the actual mount and file before the first frame, the reader restores chapter, text offset and size. A missing or invalid book leaves an accessible shelf with an error, never the embedded reading demo.
- 首页“书架”只打开书架，不再询问续读；全局菜单的书架也是明确入口，先保存正文，再进入书架，不弹续读。首页 KEY1 续读（没有记录则打开书架），KEY2 强刷，KEY3 与右下把手开菜单；阅读器三键仍为上页/工具条/下页，长按中键保留菜单出口。
  Home Library opens the shelf without a resume prompt; global-menu Library also saves/leaves the body and explicitly opens the shelf without confirmation. On home, KEY1 resumes (or opens an unread shelf), KEY2 cleans the screen and KEY3/the handle opens the menu. Reader keys remain previous/tools/next with middle-key hold for the menu.
- 导入复用原 AP/STA 传书页，离页停服务；来源变更后回首页更新记录。无卡和缺完整字库仍受原内置存储 ≤1 MiB/书、内置 GB2312 字库之外的生僻字覆盖限制。
  Import reuses the AP/STA transfer page and stops its service on exit; returning home updates records after source changes. Without TF or a complete font, the original internal ≤1 MiB/book and UI-subset font limitations apply.
- 普通书架每页三本：EPUB 封面、无封面书的生成封面或文件名排版，配多行标题、来源与保存进度；翻页/批量管理在导航上方。搜索、来源筛选、排序与长按单本管理保留；批量页仍七行，切换时按首项位置换算页码，不清除勾选。
  Ordinary shelves show three cards per page with EPUB covers, generated covers for coverless books or the typographic fallback, plus multiline titles, source and saved progress; paging/management sit above root navigation. Search, filtering, sorting and long-press management remain; batches keep seven rows and convert page indices by first item without clearing selection.
- 正文不显示四根导航；本章缺字时显示一行完整字体入口。中央点按/中键显示六项工具：目录/书签、添加书签、字号、更多设置、清除残影、书架；字号进入加减子面板，更多设置分成两组，共十二项：正文字体、行距（标准/舒展/宽松）、页边距（标准/宽/更宽）、首行缩进（两字符/关）、段落间距（标准/加大）、行辅助线（关/实线/虚线，画在每行文字下方）、对齐方式（左/居中/两端对齐，段末行保持左对齐，只影响绘制不重排）、翻页动画*（实验默认关，开时日间标准文字翻页用错相波前，16条带一拍一带、每像素完整厂家GL16相位，方向跟随翻页；直刷/灰缘/夜间不受影响，失败自动整屏恢复）、点击翻页开关（左/右 30% 分区）、晃动实验、自动翻页（关/20/40/90 秒，从上次翻页计时，工具条或插图打开时暂停并阻止空闲锁屏）、清残影周期（关/3/5/10/14/20/30 次整页更新后升一次全像素 GC16，通用页面成功更新使用，日间正文、局部按钮和分钟刷新不计数）。夜间模式已暂时下线：开关、夜间方案与白预驱入口移除，存量夜间设置不再生效恒为日间，底部为清残影与返回阅读。菜单在调整后保持打开、值就地刷新，经底部“返回阅读”或中键退出；清残影是例外，先退出设置/工具条，再完整清理正文；行距/边距/缩进/段距变更即时重排并保持文本锚点，辅助线开关按文本锚点重分页，实线/虚线切换及夜间不重分页。断行执行中文禁则：右标点（。，、！？：；』」》等）不落行首，优先悬挂进右缘留白并按 ≤3px/隙压缩字隙，放不下时连同前一个正文字下移，成串左标点整串移到下一行；两端对齐、居中与文字命中使用同一套悬挂位置。夜间统一反色READING画面，包括正文、边距、页脚、工具条及阅读覆盖层；目录、阅读设置及其它页面保留原配色。
  Reading hides root navigation; the builtin-font notice stays a tappable single line. Center tap/middle key reveals TOC, smaller/larger text, Typography, Night and shelf actions. Typography lists twelve rows: alignment (left/center/justified with left last lines, draw-only), font, leading (standard/relaxed/loose), side margins, first-line indent (two ems/off), paragraph gap (standard/relaxed), the per-line guide rule (off/solid/dashed, drawn under every text line), a page-turn animation switch (experimental, off; day standard text turns take a staggered wavefront of 16 bands one per tick with full vendor GL16 phases per pixel, heading with the turn; direct/gray-edge/night untouched with automatic whole-screen recovery on failure), the tap-zone switch (left/right 30%), the shake experiment, auto page turn (off/20/40/90 s timed from the last turn, paused while the toolbar or an image is open) and the ghost-cleanup period (off/3/5/10/14/20/30 page updates before one full-pixel GC16, for generic pages; day body, local controls and minute bands do not count). Night mode is temporarily withdrawn: the toggle, profile and pre-drive entries are removed and stored night settings no longer apply, always rendering day, with screen cleaning and return at the bottom. The menu stays open with values refreshing in place, leaving via Return or the middle key; Clean is an exception, closing settings/tools before cleaning the body; leading/margins/indent/gap repaginate at once while keeping the anchor, guide on/off repaginates at the text anchor, while solid/dashed and night changes preserve pagination. Wrapping applies CJK kinsoku: closing punctuation (。，、！？：；』」》…) never starts a line — it hangs into the right margin with per-gap squeezing of at most 3px, else moves down with the preceding body glyph, and whole runs of opening marks move down together; justification, centering and glyph hits share the hung positions. Night inverts the whole READING frame, including margins, footer and reading overlays; TOC/reader settings and other pages retain their palette.
- 目录页改为三页签：目录（章节直达）、书签（首行“＋ 为本页加书签”，最多 16 条按位置排序、满员淘汰最旧，点按跳转、长按先确认删除，随文件删除一并遗忘；“清进度”保留书签）、跳转（10%–100% 按全书字节比例估算，使用全书字节比例定位）。TXT 目录标题保存完整 UTF-8 字符，最多 96 字节；缓存规格变化后自动重建。无 NCX/NAV 的 EPUB 首次打开目录时补扫正文编号题头：h1–h3 与独立段落里“第＋中文/阿拉伯数字＋章节卷回部集”及“Chapter＋数字/罗马数字”作为候选，须其后出现普通正文才收录（连续编号的目录页互不作证），前置件按文件名与标题跳过；只填补未命名章节、不改写正式标题，超过 256 章且已有部分正式标题的大书跳过补扫。
  The TOC becomes three tabs: chapters (direct jumps), bookmarks (a leading add-row, at most 16 position-sorted entries evicting the oldest, tap to jump, long-press to confirm deletion, forgotten with file deletion while progress clears keep them) and percent jump (10%–100% estimated by whole-book bytes, using the whole-book byte locator). TXT index titles retain complete UTF-8 scalars up to 96 bytes and rebuild automatically when the cache specification changes. EPUBs without NCX/NAV scan body numbered headings on the first TOC open: h1–h3 and standalone paragraphs matching 第 + Chinese/Arabic numerals + a chapter unit, or Chapter + digits/Roman numerals, become candidates that apply only when ordinary prose follows (consecutive numbered TOC labels cannot validate each other), with front matter skipped by filename and title; only untitled chapters fill in, authored titles never rewrite, and books beyond 256 chapters with some authored titles skip the scan.
- 读完面板：在末章末页继续向前时弹出“已读完本书”，推荐最多三本同来源图书（按最近阅读优先）；点候选直接打开，“继续停留”关闭，任意翻页或三键先收面板。
  End-of-book panel: paging forward past the last page shows "finished" with up to three same-source suggestions (recency first); a candidate opens it directly, Stay closes the panel, and any turn or key dismisses it first.
- 设置子项指向产品页：阅读（默认字号 36–72 步进 4、正文字体入口、阅读状态栏时钟/电量/阅读百分比开关）、传书（复用原 AP/STA 页）、时间与时区、睡眠（浅睡/深睡/关机与浅睡拿起唤醒，写入既有 NVS 设置）、存储（TF 与内置书库只读容量检测）与诊断目录。原睡眠/TF 演示页移入诊断，仍可实际执行与格式化；字体选择器从阅读设置进入。
  Settings children point at product pages: Reading (default size 36–72 in steps of 4, body-font entry, footer clock/battery/percentage switches), Transfer (the existing AP/STA page), Time & timezone, Sleep (light/deep/off plus light-sleep pickup wake, writing the existing NVS settings), Storage (read-only TF/internal capacity probing) and the diagnostics catalog. The sleep/TF demos moved under diagnostics and still execute/format; the font picker is reached from Reading.
- 空闲自动锁屏：睡眠设置选择 关/5/10/30 分钟，任何触摸刷新计时，自动翻页会阻止空闲锁屏；到点走与电源键相同的锁屏/保存路径。
  Idle auto-lock: Sleep settings pick off/5/10/30 minutes, any touch refreshes the timer, auto page turns block it; expiry takes the same lock/save path as the power key.
- 页脚状态栏：第一行仅显示当前章节，长标题省略；第二行左侧时间/电量、右侧本章页码/全书百分比，各开关保持有效。分钟或电量变化只局推底栏，不重刷正文；预渲染翻页前重新绘制当前时间。
  Reader footer: only the current chapter on the first row with ellipsizing; clock/battery below left and chapter page/book percent right, retaining all switches. Minute/battery changes push only the footer; prepared turns repaint the current clock before presentation.
- 正在读的“同步进度”按钮针对卡片中的当前图书先拉取远端记录，以 0.01% 为单位比较：远端更远则自动写回本机，远端缺失、落后或相等则上传本地进度并回读确认；本地无记录但远端有记录时也可写回。远端请求失败或响应无效不会盲目上传，图书/本地进度在同步期间变化则不覆盖本机。结果在首页显示，不打开正文；按“停止”、切页或锁屏会取消。账号通过设置→传书→进度同步配置，网络使用已保存 WiFi。按钮保留边缘容差；阅读设置中的手动下载仍须确认。
  Home Upload Progress sends the current book's saved progress and reports on Home without opening the reader. It immediately reads back the same document record and distinguishes server confirmation, a newer retained remote position and missing confirmation. Stop/exit/lock cancel it; configure accounts under Settings → Transfer → Progress Sync and use saved WiFi. The larger button includes edge tolerance. Remote pulls remain in the reader's sync settings with confirmation; that page hides server/user details, which remain configurable on the transfer page.
- 时间页“联网对时”直接使用已保存 WiFi，无需跳转。未配置时在本页提示先配置；等待期间可停止或返回。成功、失败、30 秒超时、离页与锁屏都会释放本次网络，不启动传书 HTTP。
  Time-page network sync directly uses saved WiFi without navigation. Missing credentials show a configuration hint; Stop/Back remain available. Success, failure, a 30-second timeout, exit or lock releases the owned connection; no transfer HTTP server starts.
- 手帐沿用日期印章、统计卡片与三子页布局：今日概览（真实今日/近7日分钟、阅读天数、摘录与最近书目）、打卡月历、金句便签。统计值、子标签、日期和便签使用更大字号，长书名/便签有界换行或省略；日期来自 PMU RTC 与时区，未校时显示提示。
  Journal retains its date stamp/cards and three views: Today (real daily/7-day minutes and current-book footprint), Monthly check-ins, and Notes. Stats, tabs, calendar dates and notes use larger type with bounded wrapping/ellipsizing; dates come from PMU RTC/timezone with an uncalibrated notice.
- 校时：已有 WiFi（STA）传书会话取得网络地址后自动 SNTP 校时一次，写入 PMU TIME_SYNC 随即释放；热点模式与停止态不联网。CW32 断电/复位后时间丢失属预期，需要重新校时。
  Calibration: a STA transfer session with an uplink runs one SNTP sync, writes PMU TIME_SYNC and releases immediately; AP mode and stopped states stay offline. CW32 power-cuts reset the clock by design and need recalibration.
- 阅读统计：正文视图内累计阅读时长，空闲超过 5 分钟截断，按本地日期归日、保留最近 30 天，未校时期间不累计。统计是尽力而为的数据，不用于任何精确计费。
  Reading stats: reader-view time accumulates with a 5-minute idle cutoff, attributed to local dates keeping the newest 30 days, and skipped while uncalibrated. Stats are best-effort and never precision accounting.
- 电源键锁屏前会先运行统一保存钩子：正文进度立即落盘，阅读统计落检查点；失败不阻塞睡眠。普通翻页满 8 次的节流保存仍保留。
  Before the power-key lock runs a unified prepare hook: reader progress saves at once and stats flush a checkpoint; failures never block sleep. The 8-turn throttled save remains.
- 锁屏样式为图片/时钟/日历/黄历（睡眠设置内），默认图片：有壁纸画壁纸，无壁纸或读取失败回退内置静态图；时钟/日历/黄历取 PMU RTC 本地时间，未校时自动回退内置图；黄历面显示农历日大字、干支年/生肖/农历月与公历日期（`os_lunar` 纯换算，1900–2100 公开年表，锚点对齐春节/端午/中秋；“宜读书”为固定文案，不是逐日宜忌数据）。“图片”选择样式，标题右侧“去挑选”进入锁屏图片页：分页浏览 TF 卡 `pictures` 与 `images` 目录的 JPG/PNG（卡上文件 ≤50 MB、网页上传单文件 ≤20 MB、至多 96 张），整页 GC16 查看并可左右切换；选定后“设为锁屏”写入壁纸路径（样式即图片），“清除壁纸”回退内置图。图片解码后做 0.5%/99.5% 百分位自动色阶再按原比例居中裁切整屏绘制并做 16 级有序抖动；壁纸锁屏入口先物理清白再按厂家 GC16 重画，避免照片透出上一页残影；壁纸不随分钟变化，深睡策略与内置图一致。锁屏密码为 4 位数字，开机在主循环之前阻塞校验（菜单不可绕过），设置页可修改/清除，浅睡唤醒也校验，直接从锁屏覆盖到密码页。

## 灰缘同步起扫与夜间白预驱 / Gray-edge phase alignment and night white pre-drive

0.5.32修灰缘直刷的两段观感。用户实机确认抗锯齿满意，但翻页先显细锯齿二值字、后闪一下变好。逐相核对厂家表找到成因：黑白端点按DU20在相0-17完成，灰边迁移按8灰GL30右对齐到相27，部分15→灰的首动作迟至相14-16——扫描前半段边缘还停在旧颜色，只能看到无灰边的细字，最后约10相边缘才被驱动，形成“闪成好字”。修复只动装配：每条灰边序列去掉厂家源的前导空等，首个动作对齐相0与端点同步起扫，脉冲数与内部结构逐字保留；最长27相+1中性尾，总相31→28，翻页还快约33ms。边缘光学质量、局部闪动与最终观感仍须同字体同字号实机确认。

The fix is assembly-only: each gray sequence drops its vendor leading idle so the first action aligns to phase 0 beside the endpoints, keeping the pulse sequence byte-identical; the longest 27 phases plus one neutral tail shrink the table from 31 to 28, about 33 ms faster. Edge optical quality, local flicker and the final look still require same-font same-size device checks.

夜间黑底残影继续按同板实验推进：翻页设置的方案行拆为左右两段，右侧新增“白预驱”开关（独立bk_prewipe，默认关）。开启后普通夜间翻页的15→0（旧白字回黑底）先用白脉冲再走厂家黑迁移：标准GL路径把厂家GL48的0→0对角线逐相拷进15→0（白块正好落在原空闲相10-27，黑块28-45原位不动）；直刷/灰缘族用W6前导加完整DU20黑相。白像素上加白光学不可见，但把粒子态重置回饱和白，让随后的黑脉冲从与日间对角线定稿相同的起点出发——这正是日间每翻一页都在重洗黑像素、不留残影的机制。周期清理、入口清白、Crossmux对照和全部日间路径不变；能否减轻黑底残影未经同板验证，请开关各读若干页对比再反馈。

## 灰边单调逼近、预驱满剂量与换网连接修复 / Monotonic gray edges, full-dose pre-drive and change-of-network WiFi fix

0.5.33把灰缘直刷的中间态彻底改掉。左对齐后用户仍见先锯齿后抖动，逐相检视确认厂家灰序列是"先压过头再拉回"的过冲结构（如15→灰10为黑10相+白4相），扫描中边缘必然先变全黑再修回——对齐只能改变时刻，改不了路径。灰边现改按跟手DU同款剂量公式单调同向逼近：从旧灰朝目标打k=ceil(灰差·18/15)个同向脉冲，与字芯同向同动；表长28→21相与黑白直刷同速。代价是灰阶绝对精度不再由厂家表保证，边纹浓淡可能略有偏移，请同字体同字号实机复验。
0.5.33 reworks the gray-edge intermediate state entirely. After left-alignment the user still saw jagged-then-shake; per-phase inspection confirmed vendor gray sequences overshoot then trim (15→gray10 is ten black phases plus four white), so edges must pass fully black mid-scan — alignment changes when, not how. Gray edges now approach monotonically with the follow-DU dose formula: k=ceil(delta*18/15) same-polarity pulses from the old gray toward the target, moving with the cores; the table shrinks 28 to 21 phases, matching binary direct speed. The trade: vendor tables no longer guarantee absolute gray levels, so edge density may shift slightly — please revalidate with the same font and size.

白预驱按残影反馈升级：15→0提升为厂家0→0对角线等剂量（直刷族同样W18先白后黑，不再用W6短前导），并给保持黑底0→0新增每页W2+B18微洗——这正是日间对角线每页重洗黑像素、不积残影的机制，幅度仅约1/9，观感应是暗灰一瞬。能否除净残影与微洗是否可见均须开关对比实测；周期清理、入口与日间路径不变。Crossmux夜间对照按用户要求整体移除（存值1回当前），其波形表、出口与裁剪器删除。
The white pre-drive upgrades per ghost feedback: 15→0 rises to the full vendor 0→0 diagonal dose (W18 then B18 on the direct family, dropping the W6 short lead), and held black 0→0 gains a per-turn W2+B18 mini-wash — the very mechanism that re-washes black pixels every day turn without ghosts, at about one-ninth amplitude, expected to read as a brief dark-gray blink. The Crossmux night comparison is removed entirely per user request (stored value 1 falls back to Current), together with its waveform tables, exit and trimmer.

换网后"已保存，尚未连接"的根因是0.5.31"释放失败保留资源"的闩锁：断开失败后资源标志与stopping保持，后续所有连接在start入口被静默拒绝（ESP_ERR_INVALID_STATE无日志），重输密码只写NVS不发起连接；公司热点换到家网使每次会话都失败断开，闩锁概率大增。修复四层：已保存网络启动遇残留先重试一次停止再连接；IDF对已删除对象返回的INVALID_STATE按已释放处理；锁屏校时维护遇残留自愈重试停止；全量会话wifi-init内存不足回退6+4小缓冲重试（降速传书优先于连不上）。状态行新增"已保存，连接失败，请重试"以区分从未尝试与尝试失败；若仍失败，请提供串口`transfer`标签的`start busy …`与`wifi heap …`日志。
The saved-but-never-connected bug after changing networks roots in 0.5.31's retain-on-failed-teardown latch: after a failed disconnect the ownership flags and stopping stay set, every later connect is silently rejected at the start gate (ESP_ERR_INVALID_STATE with no log), so re-entering the password only writes NVS without connecting; switching from the office hotspot to the home network turns every session into a failed one, multiplying latch odds. The fix has four layers: starts on saved networks retry the stop once before connecting; IDF INVALID_STATE for already-deleted objects counts as released; lock-screen time maintenance self-heals residue by retrying the stop; and full-session wifi-init falls back to the 6+4 buffers once on NO_MEM (slower transfers beat no provisioning). The status line adds "已保存，连接失败，请重试" to separate never-attempted from attempted-and-failed; if it still fails, provide the serial `transfer` tag lines `start busy …` and `wifi heap …`.
