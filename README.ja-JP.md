Read Pico は、Read シリーズの開発ボードです。ESP32-S3 と 4.7 インチのモノクロ電子ペーパーディスプレイを搭載しています。
Shenzhen MindReset Technology Co., Ltd. が、電子ペーパー向けのオープンソースファームウェアを
開発する方に向けて提供しています。このブランチでは公式出荷デモを基盤に、読書優先の製品ファームウェアを開発しています。

ディスプレイ、タッチ、加速度センサー、電源、キー、TF カード、フォント、スリープと復帰の
デモ画面と診断画面を個別に用意しています。ハードウェアの動作確認や、独自ファームウェアを
開発する際のリフレッシュ制御、電力管理、操作方法の参考として利用できます。

ボードサポート、PMU プロトコルのホスト実装、各チップのドライバーは独立したコンポーネントとして
再利用できます。四つの製品ルート、書影優先ホームと3冊の本棚、簡潔な読書ツール、分類した設定を実装し、保存された履歴と明示的な続き読みに接続しています。
RTC/ToDo、設定下位画面の全面刷新、システム全体の復元は未完成で、完成した OS リリースではありません。

通常起動は「正在读」。日常ルートは「正在读 / 书架 / 今日 / 设置」で、診断は「设置 → 进阶与诊断」に配置します。ホームの続き読みは再確認せず、下部の本棚は直接開き、メニューからは従来どおり確認します。
[製品 UI の仕様・保守境界・検証](docs/READING_HOME.md) を参照してください。2 台目は開発資料待ちで、ドライバーや書き込み用イメージは未提供です。

AI エージェント向けのディレクトリ構成、`app_desc_t` の仕様、用語集、コメント規約は
[AGENTS.md](AGENTS.md) を参照してください。

読書ツールには目次・ブックマーク、追加、文字サイズ、詳細設定、残像消去、本棚を用意しています。詳細設定は文字組み、ページ送り・表示、進度同期の三組に分かれ、ブックマーク削除は確認が必要です。同期はバックグラウンドで実行し、ダウンロード位置は確認後に反映します。同期中はアップロード・削除を止め、転送画面を離れると同期をキャンセルします。ホームに常時フォント注意を表示せず、本文で文字が不足する場合のみフォント選択を案内します。


TF カードを **USB ディスク** として接続できます。設定 → ストレージ → USB 接続で確認すると再起動します。コピー後は PC で安全に取り出してから端末で終了・再起動してください。接続中は読書と WiFi 転送を停止し、終了後に書き込み用シリアルポートが復帰します。[USB 接続ガイド](docs/USB_SD.md)。


ホームと今日は完成済み概要、本棚は一覧とページを保持し、書籍・進度の変更時に更新します。ホームの本をタップすると直接開き、EPUBは実際の表紙を表示します（TXT・表紙なしは書名表示）。保存済みWiFiを再利用し、転送画面では既定で再接続します。読書ツール → 詳細設定 → 進度同期から自動接続でテスト・送受信でき、受信は確認後に反映し、他のファームウェアの位置は割合から近似します。新規設定の残像消去周期は5回、既存の設定は保持します。完全なGC16で画面全体を消去し、走査クロックは12 MHzです。復帰時の空白画面を除きPINを中央配置し、設定の有効項目にはチェックを表示します。

## ビルドと書き込み

ESP-IDF v6.1 が必要です。`components/read_pico/read_pico_flash_hpm.c` は、
v6 でのみ提供される `esp_flash_chips/spi_flash_override.h` に依存しています。

```sh
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/cu.usbmodem* flash monitor
```

`sdkconfig.defaults` の 120 MHz flash / PSRAM タイミングは、ボードに搭載された flash の型番に依存します。
CI は `sdkconfig.ci` の標準タイミングを使い、コンパイルできることのみを確認します。
[.github/workflows/build.yml](.github/workflows/build.yml) を参照してください。

開発中や書き込み時に、スリープから復帰したデバイスが認識されない場合は、次の順に試してください。

1. USB Type-A のデータケーブルに交換する。
2. デバイスを再度スリープさせてから復帰させる。
3. ボードを再起動してやり直す。

パネルの共通電圧（VCOM）は工場で校正され、PMU に保存されます。ファームウェアは起動時に
一度だけ読み取り、ドライバーを設定します。ローカルには保存せず、ユーザーによる変更機能もありません。

## デスクトップ UI プレビュー

Python 3.9+ と C コンパイラー（macOS は Xcode または Command Line Tools）で実行します。

```sh
python3 tools/preview/serve.py
```

<http://127.0.0.1:8765> で新しいホーム→本棚→本文/ページ送り/文字サイズ/ツール→戻る操作、設定、空/異常状態、従来のテストを確認できます。ESP-IDF や実機は不要です。製品 UI はネイティブ C 描画を共有し、本の状態だけホスト適応です。4冊の表示名が内蔵サンプル本文と実際のページ分割を共有し、ユーザーの本や保存進捗にはアクセスしません。完全な ESP32-S3 エミュレーターではなく、ファイル、周辺機器、物理更新、電力は実機で検証してください。
詳細は [対応範囲、制限とテスト](tools/preview/README.md) を参照してください。

## 転送と制限事項

AP と既存 WiFi の両モードで転送ページの QR コードを表示します。AP では WiFi 接続用とページを開くコードを切り替えられます。端末のビルド日時は UTC と明記します。

転送サーバーは転送画面でのみ動作し、画面を離れると停止します。個別ログインや TLS のないローカル HTTP を使用し、同じネットワークの端末から対象ストレージの本を管理できるため、信頼できるネットワークで使用してください。WiFi 認証情報は端末 NVS に保存され、公開 API やログにパスワードを返しません。NVS/flash 暗号化は有効化しておらず、物理アクセスへの保護は提供しません。

転送を停止すると、入る前の画面またはメニュー位置に戻ります。マウント済みTFカードが使用できなくなると、関連する読書・転送を停止し、内蔵フォントに戻ります。再挿入後はTF画面で明示的に再マウントしてください。書き込み中にカードを抜くとファイルシステムが破損する可能性があります。EPUBの章を開く際にローカルJPEG/PNGを自動で読み込み、本文と一緒に組版します。1章につき最大64枚を試行し、768 KiBのグレースケール予算を共有して比例縮小します。失敗や上限超過時はタップ可能なプレースホルダーを残し、別画面のプレビューから元の位置へ戻れます。ページ送りや描画では再デコードしません。ZIPエントリー、manifest項目、spine章はそれぞれ最大32768件、OPF・ナビゲーションは展開後4 MiB、本文・画像の読み込みは2 MiB、ZIP中央ディレクトリは8 MiBまでです。見出しの合計予算は1 MiBで、超過分は番号見出しになります。未使用エントリーも4 MiBを超えると拒否します。章数とは別にメモリー・リソース上限があり、ZIP64と32768件・章を超える本は非対応です。外部で置き換えた本や別のカードのファイルが同じパス・サイズの場合、以前の読書位置が適用されることがあります。保存失敗後の再試行状態は、電源断後の保持を保証しません。

本棚に入ると前回の読書を再開するか確認します。キャンセルすると本を開かず本棚に留まります（KEY1でキャンセル、KEY3で再開）。目次と現在の章を解析し、最初の2ページまたは保存位置までを先に組版します。残りは2ページずつ追加し、他の章は必要時に読み込みます。未完了の総ページ数は「…」と表示し、前章の末尾へ戻る場合はその章全体の組版が必要です。文字幅は常駐フォント表から計算し、章全体の字形画像を事前生成しません。待機表示と失敗理由（メモリ不足・上限超過・非対応形式・ファイル異常）は引き続き表示します。

スワイプによるページ送りは指を離した時点で確定し、距離は120から64ピクセルに短縮しました。タップ許容範囲の24ピクセルを超え、64未満のドラッグはキャンセルします。画像プレースホルダー上のスワイプは画像を読み込まずページを送ります。

挿絵の上限：ベースラインJPEGはデコード時の縮小を優先し、表示サイズへの拡大を最大2倍まで許容し、元画像16M画素・各辺8192まで。PNGとプログレッシブJPEGは1M画素・デコードヒープ4 MiBまで。出力は648×1000以内のグレースケールで、透過PNGは白背景に合成します。本文中の画像は章と一緒に解放し、拡大プレビューには最後に閲覧した1枚を追加でキャッシュし、同じ画像を開き直す際に再利用します。上限超過・欠落・破損・非対応画像はタップ時に理由を示し、本文の読書は継続できます。同じ正規化リソースパスの繰り返しには「重复图片」と、今回開いてから閲覧した章の最小節番号を表示します（表紙や前書きを含むEPUB順序のため本文の章番号と異なる場合があります）。章頭の画像群に見出しが直続する場合、その画像と同じリソースへの参照は「标题图」と表示し、最初の位置表示を省きます。その他の挿絵は既読の最小節番号を保持します。未読章は走査せず、全書で最初の出現とは断定しません。記録は本を閉じると消去され、別パスの同一内容は照合しません。SVG内のJPEG/PNG参照は対応し、純粋なSVGベクター・CSS背景・外部画像は非対応です。[デコーダーの出典とライセンス](main/book/vendor/README.md)も参照してください。

内蔵フォントにはGB2312の漢字6763文字、句読点とUI文字を収録し、カードなしでも一般的な中国語の書名と本文を表示します。稀な文字・追加の繁体字や他言語には、文字を十分に収録したTTFをTFカードの `fonts/` または `assets/fonts/` に置き、「字体 Font」画面で選択してください。既定のパスは `fonts/ChillDuanSansVF.ttf` です。文字が欠ける場合はファイルの有無とフォントの収録文字を確認してください。[TF 配置用フォントとライセンス](sdcard/README.md)を同梱しています。Web の「上传字体」から `/sdcard/fonts` へアップロードできます。TrueType アウトラインの TTF のみ、1ファイル32 MiBまで（OTF/CFF・TTC・WOFFは非対応）。容量を確認し、同名置換には確認が必要です。中断・検証失敗時は元の字体を保持します。転送停止後に端末で字体を選択してください。転送中は内蔵字体を使用し、保存済みの選択は変更しません。

機能の変更は [変更履歴](docs/CHANGELOG.md) を参照してください。拼音データは MIT ライセンスの pypinyin に由来します。[ライセンスと再生成](components/read_pico_search/README.md)を参照してください。
