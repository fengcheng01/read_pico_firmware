Read Pico は、Read シリーズの開発ボードです。ESP32-S3 と 4.7 インチのモノクロ電子ペーパーディスプレイを搭載しています。
Shenzhen MindReset Technology Co., Ltd. が、電子ペーパー向けのオープンソースファームウェアを
開発する方に向けて提供しています。このブランチでは公式出荷デモを基盤に、読書優先の製品ファームウェアを開発しています。

ディスプレイ、タッチ、加速度センサー、電源、キー、TF カード、フォント、スリープと復帰の
デモ画面と診断画面を個別に用意しています。ハードウェアの動作確認や、独自ファームウェアを
開発する際のリフレッシュ制御、電力管理、操作方法の参考として利用できます。

ボードサポート、PMU プロトコルのホスト実装、各チップのドライバーは独立したコンポーネントとして
再利用できます。四つの製品ルート、書影優先ホームと3冊の本棚、簡潔な読書ツール、分類した設定を実装し、保存された履歴と明示的な続き読みに接続しています。
RTC/ToDo、設定下位画面の全面刷新、システム全体の復元は未完成で、完成した OS リリースではありません。

通常起動は「正在读」。日常ルートは「正在读 / 书架 / 今日 / 设置」で、診断は「设置 → 进阶与诊断」に配置します。ホームの続き読みは再確認せず、下部とメニューの本棚は直接開き、読書中の進捗は離れる前に保存します。
[製品 UI の仕様・保守境界・検証](docs/READING_HOME.md) を参照してください。2 台目は開発資料待ちで、ドライバーや書き込み用イメージは未提供です。

AI エージェント向けのディレクトリ構成、`app_desc_t` の仕様、用語集、コメント規約は
[AGENTS.md](AGENTS.md) を参照してください。

読書ツールには目次・ブックマーク、追加、文字サイズ、詳細設定、残像消去、本棚を用意しています。残像消去はツール・読書設定を閉じてから本文を消去します。詳細設定は文字組み、ページ送り・表示、進度同期の三組に分かれ、ブックマーク削除は確認が必要です。同期はバックグラウンドで実行し、ダウンロード位置は確認後に反映します。同期中はアップロード・削除を止め、転送画面を離れると同期をキャンセルします。ホームに常時フォント注意を表示せず、本文で文字が不足する場合のみフォント選択を案内します。

**0.5.30-20261009.1**は実機結果に基づき「黒基準」と「字縁：細辺」を撤回します。黒基準の消去直後の最初のページにも残像と点滅があり、細辺も目に見えるアンチエイリアス改善がありませんでした。元の直接描画と、現在の夜間方式の物理的白消去＋完全GCを戻します。通常送りに追加消去はなく、消去間には残像が累積する場合があります。保存済みの黒基準は「当前」へ戻り、旧キー・進捗・他の設定は消去しません。

0.5.29の時刻学習状態、静止画の浅いスリープ保守、WiFiスキャン改善は保持し、ユーザーのホットスポットはスキャン可能になりました。初回の信頼できる同期後は再起動せず少なくとも1時間ロックし、2回目の同期で補正を保存してから更新を検討してください。書き込みの再起動は未完了の学習期間を失いますが、同モデルの保存済み補正は保持します。白黒DUに本来の灰階アンチエイリアスはなく、本版は夜間残像やオフライン精度の解決を主張しません。

**0.5.28-20261008.1**はSDの`.read-pico-cache`にEPUB書影とTXT目次を保存し、再起動後も再利用します。上限は128件/8MiBで、同名ファイルの置換は元データの識別情報で検出します。破損や書込み失敗は元の処理へ戻り、書籍・進捗を変更しません。TXTのヒット時も内容確認の順次読込みは必要ですが、目次解析を省きます。⋯がないフォントでは同じフォントの…を使用し、本来の字形を優先します。走査キューの残留統計と制限付き異常ログを追加し、通常更新は変えません。

睡眠時計の補正をモデル識別付きで保存し、今回の更新では識別のない旧補正を使いません。一度同期し、再起動せず少なくとも1時間ロックしてから2回目の信頼できる同期で再学習してください。その後の同モデル更新では新記録を保持します。RTC復元は時刻範囲を検証し、失敗や短い読取りを同期成功と扱いません。Murphy M4の独立RX8010とPicoのPMU内蔵発振器は異なるため同じ精度は保証しません。ユーザーの実機ではCrossmux夜間比較でも黒背景の残像が累積します。本版は選択方式・消去周期を保持し、光学的残像の解消を主張しません。


TF カードを **USB ディスク** として接続できます。設定 → ストレージ → USB 接続で確認すると再起動します。コピー後は PC で安全に取り出してから端末で終了・再起動してください。接続中は読書と WiFi 転送を停止し、終了後に書き込み用シリアルポートが復帰します。[USB 接続ガイド](docs/USB_SD.md)。


ホームと今日は完成済み概要、本棚は一覧とページを保持し、書籍・進度の変更時に更新します。ホームの本をタップすると直接開き、EPUBは実際の表紙を表示します（TXT・表紙なしは書名表示）。保存済みWiFiを再利用し、転送画面では既定で再接続します。読書ツール → 詳細設定 → 進度同期から自動接続でテスト・送受信でき、受信は確認後に反映し、他のファームウェアの位置は割合から近似します。一般画面・夜間ページ送りの新規残像消去周期は5回、既存の設定は保持します。一般画面と現在方式の消去は完全なGC16で画面全体を更新し、走査クロックは12 MHzです。復帰時の空白画面を除きPINを中央配置し、設定の有効項目にはチェックを表示します。

読書ツール → 詳細設定 → ページ送り・表示で、アンチエイリアスを保つ標準灰階（既定）か、メーカー白黒DUの直接更新を選べます。直接更新は灰色の縁を残しません。昼間の標準は黒・灰色の不変画素を再定着し、現在方式の夜間は従来の保持で黒背景の全面白点滅を避けます。夜間は余白・フッター・ツール・読書画像プレビューも暗色になり、目次や設定などは元の配色を保ちます。現在の夜間方式は保存済み消去周期を使用し、0で無効、両ページ送りモード共通の成功N回目、手動消去、現在方式の夜間本文へ戻る実際のレイアウト境界では、パネルを物理的に白く消去してから保持した本文をGC16で1回描画します。昼間は周期消去せず、従来の消去経路を保ちます。現在方式の夜間消去は時間が長くなり、白消去中に明暗が複数回点滅する場合があります。残像ゼロは保証しません。タッチキューは走査中の完全なタップを保持します。

**0.5.27-20261008.1**では、読書ツール → 詳細設定 → ページ送り・表示の夜間方式にCrossmux比較を追加しました（画面表示 `更多设置 → 翻页显示 → 夜间方案：Crossmux`）。新規・更新とも既定は「当前」（現在方式）です。文字のみの夜間ページは白黒DU20に固定され、標準灰階を選択していても灰色の縁は残りません。デコード済み画像を含む章、読書パネル、操作部、分単位更新、昼間は従来の経路を保ちます。参照が既知なら入口はGL37を1回使い、設定や表示済みパネルから本文への復帰も本ファームウェアの適応として含めます。周期・手動消去は事前の物理白消去なしでGC36を1回使います。参照が未知なら従来の物理白消去と完全GC48による復旧を保ちます。保存済み周期と他の選択は保持し、失敗を数えず、成功した消去または比較方式の入口で回数をリセットします。

これは[Crossmux Pico](https://github.com/0x1abin/crossmux/tree/1512e8e049f2b1a4efc7c004a5b1a93cbc5e3f9f)の波形と更新方針の比較です。本ファームウェアの走査は12 MHz・127行プリフィルを保持し、[関連SDK](https://github.com/0x1abin/freeink-sdk/blob/96de1be6ce08eb732909e6e8149af8f892b9a2c5/libs/hardware/BoardReadPico/src/ReadPicoEpdiyConfig.cpp)の18 MHz・32行とは異なります。Crossmux全体や基板の走査タイミングの置換ではありません。61件のホストUIテストはASAN/UBSAN下で通過しましたが、実機ではCrossmuxの夜間残像が累積し、残像解消・白さの改善・無点滅は保証しません。

本棚の検索入口とキーボードは押下時に走査せず、完全なタップ後に入力欄だけを白黒直接更新します。連続入力中は部分更新を続け、最後の表示終了から入力なしで2秒経つと入力欄を部分灰階更新で整えます。失敗時は2秒後に再試行します。キャンセルは適用済み検索を保ち、適用時だけ照合します。64文字制限と拼音・頭文字・英語の照合は変わりません。

文字のみの章で行補助線を有効にすると、本文・見出し・段落を共通グリッドに揃え、旧ページの線が新しい文字を横切らない配置にします。直接更新の線は昼間が黒、夜間が白です。有効・無効の切替は文字位置を保って再ページ分割し、実線・破線の切替は描画だけを変更します。補助線なしと画像を含む章は元の組版を保ちます。0.5.20の補助線と直接更新の速度はユーザーの実機で確認済みです。夜間の残像と選択した消去周期の効果は実機比較が必要で、白さや物理的残像の解消は保証しません。[更新仕様とテスト](docs/READING_HOME.md)を参照してください。

0.5.26は実機結果に基づき0.5.25の夜間実験を撤回します。残像は改善せず、DU後の局所消去は旧文字の点滅を増やしました。設定入口と追加走査を削除し、保存済み実験値を無視します。夜間・直接更新・消去周期の設定は保持します。通常夜間の残像は未解決で、手動および定期の完全消去が現在ユーザー確認済みの有効な経路です。

下部タイトルは章名だけです。睡眠時計の補正率はネット時刻との実測から学習・保存し、睡眠時間だけに適用します。更新後に一度同期し、再起動せずロック中の睡眠を経て2回目の時刻を取得してください。自動維持は時間画面で設定でき、長時間の精度は実機比較が必要です。

0.5.15は時間画面に既定で有効なロック中の自動時刻同期を追加します。更新後に一度同期し、再起動せず約1時間ロックすると睡眠中の補正率を自動学習し、その後は6時間ごとに同期します。保存済みWiFiのみ使用し、1回最大30秒、失敗後は1時間待ち、解除時に中止します。無効化も可能です。時間画面に実測ppmと保存状態を表示し、オフライン時も保存済み補正を使います。長時間精度は実機確認が必要です。EPUBのKOReader同期は実際の章・段落パスを優先し、段落位置として表示します。TXT・非対応構造はrp1を保持し、解析できない位置は割合で近似し、受信は確認後に適用します。

アプリ・メニューの実際のレイアウト切替、読書ビューの変更、表示済み読書パネルから本文へ戻る時は境界更新を1回実行します。現在方式の夜間本文へ戻る時は物理的な白消去後にGC16で本文を描画し、複数回点滅する場合があります。適用可能なCrossmux比較方式の入口はGL37を使い、昼間は実際の旧フレームからのGC16を保ちます。通常再描画・ボタン・読み込みtickでは境界消去を繰り返さず、夜間ページ送りは別途設定周期に従います。ホームは保存済み進捗を送信し、読書内同期画面は操作と結果を表示します。アカウントは転送画面で設定します。EPUB同期は葉テキストノードとUnicode文字位置を保存し、非対応構造は近似位置を表示して受信前に確認します。実機間の精度は同じ本で比較してください。

## ビルドと書き込み

ESP-IDF v6.1 が必要です。`components/read_pico/read_pico_flash_hpm.c` は、
v6 でのみ提供される `esp_flash_chips/spi_flash_override.h` に依存しています。

```sh
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/cu.usbmodem* flash monitor
```

`sdkconfig.defaults` の 120 MHz flash / PSRAM タイミングは、ボードに搭載された flash の型番に依存します。
CI は `sdkconfig.ci` の標準タイミングを使い、コンパイルできることのみを確認します。
[.github/workflows/build.yml](.github/workflows/build.yml) を参照してください。

開発中や書き込み時に、スリープから復帰したデバイスが認識されない場合は、次の順に試してください。

1. USB Type-A のデータケーブルに交換する。
2. デバイスを再度スリープさせてから復帰させる。
3. ボードを再起動してやり直す。

パネルの共通電圧（VCOM）は工場で校正され、PMU に保存されます。ファームウェアは起動時に
一度だけ読み取り、ドライバーを設定します。ローカルには保存せず、ユーザーによる変更機能もありません。

## デスクトップ UI プレビュー

Python 3.9+ と C コンパイラー（macOS は Xcode または Command Line Tools）で実行します。

```sh
python3 tools/preview/serve.py
```

<http://127.0.0.1:8765> で新しいホーム→本棚→本文/ページ送り/文字サイズ/ツール→戻る操作、設定、空/異常状態、従来のテストを確認できます。ESP-IDF や実機は不要です。製品 UI はネイティブ C 描画を共有し、本の状態だけホスト適応です。4冊の表示名が内蔵サンプル本文と実際のページ分割を共有し、ユーザーの本や保存進捗にはアクセスしません。完全な ESP32-S3 エミュレーターではなく、ファイル、周辺機器、物理更新、電力は実機で検証してください。
詳細は [対応範囲、制限とテスト](tools/preview/README.md) を参照してください。

| しおりと移動 | 目次ページは3タブ：章の移動、しおり（1冊16件まで、タップで移動・長押しで削除、削除時に一緒に消去）、10%–100% のパーセント移動 |
| 読了のおすすめ | 最終ページから先へ進むと、同じ保存先の本を最大3冊（最近順）提案するパネルを表示 |
| 読書ステータスバー | フッターの時計/電池残量/読書進捗率切替、目盛りなし；今日ページに常時電池表示 |
| アイドルロック | 5/10/30 分無操作で自動ロック（自動ページ送り中は抑制） |

| デバイス機能テスト | デバイスの応答確認とコマンド ACK。電源断を伴う項目はバックエンドにのみ結果を記録 |
| 図書 | TF カードまたは内蔵ストレージの UTF-8 / GBK TXT と EPUB、目次、文字サイズ、本ごとの読書位置。左右スワイプでページ送り、本文の長押しで目次、本棚項目の長押しで詳細表示、読書位置の消去、確認付き削除。保存先フィルター、名前・最近読んだ順の並べ替え、ピンイン・頭文字・英語での検索に対応。単独操作はポップアップ、管理ページは複数選択、読書位置の消去・削除、再スキャンに対応。振って次ページへ進む実験機能は既定で無効。EPUB は NCX と nav の目次に対応。 |

図書の KEY1 / KEY2 / KEY3 は前ページ / ツールバー / 次ページです。ツールバーには全画面更新があります。中央キーを500 ms長押しするとデモメニューを開けます。他のページでは KEY2 の全画面 GC16 更新と KEY3 のメニューを維持します。メニュー項目は指を離すと確定し、外へ滑らせるとキャンセルします。

電子ペーパーの電源イネーブル、XOE、MODE、VCOM_EN、タッチリセット、カード検出は
FCA9555 の Port-0 に接続されています。[main/apps/app_ioe.c](main/apps/app_ioe.c) のピン定義表を参照してください。

起動画面と静止ロック画像は展開後に画面方向へ回転し、起動時の縦縞を防ぎます。標準の昼間はメーカーGL48の全遷移と黒・灰色の対角成分に中性1相を加え、現在方式の夜間は同じ相数で変化遷移と不変保持を続けます。現在方式の白黒直接更新はDU20相に中性1相を保ち、任意のCrossmux夜間比較は上記のDU20/GL37/GC36を使います。通常のルートタブ・メニュー・手帳はメーカーGL49、実際のレイアウト境界は1回消去し、現在方式の夜間描画対象は物理的な白消去後に完全GC16で表示し、比較方式の適用可能な入口はGL37を使います。通常GLの白背景は保持し、旧文字履歴を追加消去せず、実際の参照フレームは成功時だけ確定します。MODE/XOEは基板の電源シーケンスのみが制御します。昼間は周期GC16を行わず、夜間の両モードは成功ページ送りの設定周期を共有します。失敗は数えず、成功した消去または比較方式の入口で回数をリセットします。ボタンや分単位の部分更新では全画面消去を行いません。通常更新後は直ちに画面電源を切ります。最近の読書は件数表示とページ送りで全記録にアクセスできます。ホームの「アップロード」は保存済み進捗を送信し、ダウンロードは同期設定で確認します。本文の文を長押しして抜粋を保存すると、手帳から最新16件の抜粋を表示し原文位置へ戻れます。既存のしおりは目次に残ります。ロック中の浅いスリープは分周高速RCを使用し、起床後も時間基準を保持します。更新後に一度ネット時刻同期を行い、長時間の精度と画面効果は実機で確認してください。読書フッターは2行表示を保ち、分の変化ではフッターのみ更新します。

## 転送と制限事項

AP と既存 WiFi の両モードで転送ページの QR コードを表示します。AP では WiFi 接続用とページを開くコードを切り替えられます。端末のビルド日時は UTC と明記します。

転送サーバーは転送画面でのみ動作し、画面を離れると停止します。個別ログインや TLS のないローカル HTTP を使用し、同じネットワークの端末から対象ストレージの本を管理できるため、信頼できるネットワークで使用してください。WiFi 認証情報は端末 NVS に保存され、公開 API やログにパスワードを返しません。NVS/flash 暗号化は有効化しておらず、物理アクセスへの保護は提供しません。

転送を停止すると、入る前の画面またはメニュー位置に戻ります。マウント済みTFカードが使用できなくなると、関連する読書・転送を停止し、内蔵フォントに戻ります。再挿入後はTF画面で明示的に再マウントしてください。書き込み中にカードを抜くとファイルシステムが破損する可能性があります。EPUBの章を開く際にローカルJPEG/PNGを自動で読み込み、本文と一緒に組版します。1章につき最大64枚を試行し、768 KiBのグレースケール予算を共有して比例縮小します。失敗や上限超過時はタップ可能なプレースホルダーを残し、別画面のプレビューから元の位置へ戻れます。ページ送りや描画では再デコードしません。ZIPエントリー、manifest項目、spine章はそれぞれ最大32768件、OPF・ナビゲーションは展開後4 MiB、本文・画像の読み込みは2 MiB、ZIP中央ディレクトリは8 MiBまでです。見出しの合計予算は1 MiBで、超過分は番号見出しになります。未使用エントリーも4 MiBを超えると拒否します。章数とは別にメモリー・リソース上限があり、ZIP64と32768件・章を超える本は非対応です。外部で置き換えた本や別のカードのファイルが同じパス・サイズの場合、以前の読書位置が適用されることがあります。保存失敗後の再試行状態は、電源断後の保持を保証しません。

本棚や本を開く明示的な要求がない場合のみ、前回の読書を再開するか確認します。キャンセルすると本を開かず本棚に留まります（KEY1でキャンセル、KEY3で再開）。目次と現在の章を解析し、最初の2ページまたは保存位置までを先に組版します。残りは2ページずつ追加し、他の章は必要時に読み込みます。未完了の総ページ数は「…」と表示し、前章の末尾へ戻る場合はその章全体の組版が必要です。文字幅は常駐フォント表から計算し、章全体の字形画像を事前生成しません。待機表示と失敗理由（メモリ不足・上限超過・非対応形式・ファイル異常）は引き続き表示します。

スワイプによるページ送りは指を離した時点で確定し、距離は120から64ピクセルに短縮しました。タップ許容範囲の24ピクセルを超え、64未満のドラッグはキャンセルします。画像プレースホルダー上のスワイプは画像を読み込まずページを送ります。

挿絵の上限：ベースラインJPEGはデコード時の縮小を優先し、表示サイズへの拡大を最大2倍まで許容し、元画像16M画素・各辺8192まで。PNGとプログレッシブJPEGは1M画素・デコードヒープ4 MiBまで。出力は648×1000以内のグレースケールで、透過PNGは白背景に合成します。本文中の画像は章と一緒に解放し、拡大プレビューには最後に閲覧した1枚を追加でキャッシュし、同じ画像を開き直す際に再利用します。上限超過・欠落・破損・非対応画像はタップ時に理由を示し、本文の読書は継続できます。同じ正規化リソースパスの繰り返しには「重复图片」と、今回開いてから閲覧した章の最小節番号を表示します（表紙や前書きを含むEPUB順序のため本文の章番号と異なる場合があります）。章頭の画像群に見出しが直続する場合、その画像と同じリソースへの参照は「标题图」と表示し、最初の位置表示を省きます。その他の挿絵は既読の最小節番号を保持します。未読章は走査せず、全書で最初の出現とは断定しません。記録は本を閉じると消去され、別パスの同一内容は照合しません。SVG内のJPEG/PNG参照は対応し、純粋なSVGベクター・CSS背景・外部画像は非対応です。[デコーダーの出典とライセンス](main/book/vendor/README.md)も参照してください。

内蔵フォントにはGB2312の漢字6763文字、句読点とUI文字を収録し、カードなしでも一般的な中国語の書名と本文を表示します。稀な文字・追加の繁体字や他言語には、文字を十分に収録したTTFをTFカードの `fonts/` または `assets/fonts/` に置き、「字体 Font」画面で選択してください。既定のパスは `fonts/ChillDuanSansVF.ttf` です。文字が欠ける場合はファイルの有無とフォントの収録文字を確認してください。[TF 配置用フォントとライセンス](sdcard/README.md)を同梱しています。Web の「上传字体」から `/sdcard/fonts` へアップロードできます。TrueType アウトラインの TTF のみ、1ファイル32 MiBまで（OTF/CFF・TTC・WOFFは非対応）。容量を確認し、同名置換には確認が必要です。中断・検証失敗時は元の字体を保持します。転送停止後に端末で字体を選択してください。転送中は内蔵字体を使用し、保存済みの選択は変更しません。

機能の変更は [変更履歴](docs/CHANGELOG.md) を参照してください。拼音データは MIT ライセンスの pypinyin に由来します。[ライセンスと再生成](components/read_pico_search/README.md)を参照してください。
